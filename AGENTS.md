# Repository instructions

- Keep each skill's source under `skills/<name>/`. Start with [the development guide](docs/development.md) when authoring a skill.
- Match the directory name to the `name` field in `SKILL.md`. Add `SKILL.md` once the skill has usable instructions.
- Use English for public documentation and generic examples for fixtures.
- Use Conventional Commits. Do not add `Co-authored-by` trailers for AI assistants.
