# Repository instructions

- Keep each skill's source under `skills/<name>/`. Start with [the development guide](docs/development.md) when authoring a skill.
- Match the directory name to the `name` field in `SKILL.md`. Add `SKILL.md` once the skill has usable instructions.
- Keep the root and skill README files in English with matching `README.es.md` translations and reciprocal language links. Keep shared skill instructions in English and use generic examples for fixtures.
- This repository is maintained exclusively by Enzo-Palavicino. Preserve owner-only GitHub policies and public read access. Document actual enforced settings separately from future recommendations.
- Use Conventional Commits. Do not add `Co-authored-by` trailers for AI assistants.
