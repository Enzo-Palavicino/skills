# Security policy

## English

These skills give instructions to an agent that acts using the tools and permissions in its host environment. Review the proposed operation and target repository or board when authorizing an external action. Protect credentials through the agent's connection or credential manager, and use sanitized examples when sharing results.

Enzo Palavicino manages security changes and repository access. If you discover a vulnerability, use an available private contact on the [maintainer's profile](https://github.com/Enzo-Palavicino). Share the affected skill and revision, expected behavior, a sanitized reproduction, and observed impact through that private channel. Keep credentials and private project data out of public reports.

The [governance record](docs/governance.md) describes branch and tag controls, creation policies, and temporary conversation limits. GitHub's secret scanning and push protection are enabled for this public repository. Check local skill behavior against each target project's rules.

## Español

Estas skills dan instrucciones a un agente que utiliza las herramientas y permisos de su entorno. Revisa la operación propuesta y el repositorio o tablero de destino al autorizar una acción externa. Protege las credenciales mediante la conexión o gestor de credenciales del agente y utiliza ejemplos anonimizados al compartir resultados.

Enzo Palavicino gestiona los cambios de seguridad y los accesos al repositorio. Si descubres una vulnerabilidad, utiliza un contacto privado disponible en el [perfil del mantenedor](https://github.com/Enzo-Palavicino). Comparte por ese canal la skill y revisión afectadas, el comportamiento esperado, una reproducción anonimizada y el impacto observado. Conserva las credenciales y los datos privados de los proyectos fuera de los informes públicos.

El [registro de administración](docs/governance.md#español) describe los controles sobre ramas y etiquetas, las políticas de creación y los límites temporales de conversación. Este repositorio público tiene habilitados la detección de secretos y el bloqueo de pushes que contienen secretos. Comprueba el comportamiento de las skills según las reglas del proyecto de destino.
