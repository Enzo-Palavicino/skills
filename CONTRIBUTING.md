# Maintenance policy

## English

Enzo Palavicino (`Enzo-Palavicino`) is the sole maintainer of this repository. Repository access, issues, pull requests, commits, merges, tags, releases, and configuration are managed by the owner using their authorized account and tools. Public availability lets others read, install, and reuse the skills under the MIT License.

The owner keeps changes focused on one skill or repository concern, follows [the development guide](docs/development.md), and updates the catalog and both README languages together. Use fictional or sanitized fixtures. Check links, validate changed skill metadata, and report the scenarios actually run. Use Conventional Commits and omit AI coauthor trailers, following [AGENTS.md](AGENTS.md).

The repository's enforced access settings are described in [governance](docs/governance.md). Installing these skills in another project follows that project's policies and permissions.

## Español

Enzo Palavicino (`Enzo-Palavicino`) es el único mantenedor de este repositorio. El propietario gestiona los accesos, issues, pull requests, commits, integraciones, etiquetas, publicaciones y configuración mediante su cuenta y herramientas autorizadas. La disponibilidad pública permite consultar, instalar y reutilizar las skills bajo la licencia MIT.

El propietario mantiene cada cambio enfocado en una skill o necesidad del repositorio, sigue la [guía de desarrollo](docs/development.md) y actualiza el catálogo y ambos idiomas de los README. Utiliza ejemplos ficticios o anonimizados. Comprueba los enlaces, valida los metadatos de las skills modificadas e informa los escenarios que realmente se ejecutaron. Utiliza Conventional Commits y omite coautores de IA, siguiendo [AGENTS.md](AGENTS.md).

Los accesos aplicados se describen en la [documentación de administración](docs/governance.md#español). La instalación de estas skills en otro proyecto sigue las políticas y permisos de ese proyecto.
