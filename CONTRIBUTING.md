# Contributing

Keep each change focused on one skill or one repository concern. For a new skill, follow the [development guide](docs/development.md) and update the catalog in [README.md](README.md) when its status changes.

Use fictional or sanitized examples and fixtures. Before opening a pull request, check Markdown links, validate any changed `SKILL.md`, and report the scenarios you ran and the environments you verified.

Use Conventional Commits, for example `docs: clarify skill installation`. Follow the repository instructions in [AGENTS.md](AGENTS.md).
